### Reading Rates Off a Sparse Term Structure

`N` knots `(T[i], Y[i])`: maturity in years and rate in percent, strictly increasing in `T`. For each of `M` requests `Q[j]`:

- on a knot: `Y[i]`;
- between knots `T[i] < Q < T[i+1]`: linear interpolation, `Y[i] + (Y[i+1] − Y[i]) · (Q − T[i]) / (T[i+1] − T[i])`;
- before the first knot: `Y[0]`; after the last: `Y[N−1]` (no extrapolation).

Input: `N`, then `N` lines `T Y`, then `M`, then the `M` requests on one line. Every number has exactly two decimals.
Output: the `M` rates on one line, each with exactly 4 decimals.

Constraints: `2 ≤ N ≤ 1000`, `1 ≤ M ≤ 1500`, `0.10 ≤ T[0] < … < T[N−1] ≤ 50.00`, `0.01 ≤ Y ≤ 20.00`, `0.00 ≤ Q ≤ 60.00` (any order, may repeat). No exact answer is a rounding tie.

Examples (all three from the source are used as samples):

| Knots | Requests | Output |
|---|---|---|
| (1.00, 4.50) (2.00, 4.80) (5.00, 5.20) | 1.50 6.00 | 4.6500 5.2000 |
| (0.50, 3.10) (2.00, 3.70) (7.00, 4.20) (10.00, 4.05) | 0.25 2.00 4.50 8.50 12.00 | 3.1000 3.7000 3.9500 4.1250 4.0500 |
| (1.00, 6.00) (3.00, 5.00) | 2.00 1.00 3.00 | 5.5000 6.0000 5.0000 |
